# Gift Tracking

`Gift Tracking` отслеживает появление новых коллекционных подарков Telegram и отправляет уведомление через вашего бота. В уведомлении есть ссылка на подарок, публичный владелец, модель, фон, символ, редкость, тираж и время обнаружения.

## Как работает мониторинг

1. Пользовательская MTProto-сессия получает официальный каталог подарков через `payments.getStarGifts`.
2. Для каждой уже активной unique-коллекции монитор открывает подарок `#1` через `payments.getUniqueStarGift` и читает `availability_issued`.
3. Когда счётчик вырос, монитор запрашивает новые последовательные номера, сохраняет их в SQLite и отправляет сообщение через Bot API.
4. SQLite не допускает повторных уведомлений и сохраняет неотправленные сообщения после перезапуска.

Точное время апгрейда Telegram глобально не публикует. Поэтому уведомление содержит точное **время обнаружения**. Обычный бот также не может выполнять мониторинг сам: для чтения публичного gift API нужна пользовательская MTProto-сессия.

## Подготовка

Понадобятся:

- `api_id` и `api_hash` пользовательского приложения с <https://my.telegram.org/apps>;
- бот, созданный через `@BotFather` с отображаемым именем `Gift Tracking`;
- ваш числовой Telegram `chat_id`;
- Python 3.11 или новее.

Сначала откройте созданного бота и нажмите **Start**, иначе бот не сможет отправить вам первое сообщение.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Заполните `.env`, затем запустите:

```bash
gift-tracking --test-notification
gift-tracking
```

Первая команда проверяет токен и `chat_id`, отправляя одно тестовое сообщение. Вторая запускает постоянный мониторинг.

При первом запуске Telethon запросит номер телефона, код Telegram и пароль 2FA, если он включён. После входа рядом появится файл `gift_tracking.session`; не передавайте его другим людям.

Первый запуск только фиксирует текущие номера и не присылает старые подарки. После этого каждое увеличение `availability_issued` создаёт уведомление. Для тестовой отправки последних подарков можно временно поставить `BACKFILL_COUNT=1` до первого запуска с новой базой данных.

## Фильтрация уведомлений

Можно слать уведомления только по тем подаркам, владельцу которых реально можно написать через Telegram. Для этого включите фильтр по публичному username:

```dotenv
REQUIRE_OWNER_USERNAME=true
```

В текущей реализации это означает: уведомление придёт только если у владельца есть публичный `@username`. Если владелец скрыт, указан только TON-адрес или username отсутствует, такой подарок будет пропущен.

Дополнительно можно отсеять маркетплейсы и склады по части username:

```dotenv
BLOCKED_OWNER_USERNAME_SUBSTRINGS=bank,storage
```

Сравнение идёт по подстроке без учёта регистра. Например, будут отброшены `giftbank`, `storage_nft`, `TonBankMarket` и похожие имена. Список можно расширять через запятую.

Также можно фильтровать по фону:

```dotenv
BACKDROP_FILTERS=Coral Red,Ocean Blue
```

Сравнение идёт по названию фона без учёта регистра. Если `BACKDROP_FILTERS` пустой, фильтр не применяется. Если список задан, в меню `/filters` можно временно включать и выключать этот фильтр без перезапуска.

Меню `/filters` теперь позволяет редактировать фильтры прямо из Telegram:

- включать и выключать режим `только с @username`;
- включать и выключать фильтр по фону;
- менять список `BACKDROP_FILTERS` прямо сообщением;
- менять список `BLOCKED_OWNER_USERNAME_SUBSTRINGS` прямо сообщением.

Изменения, внесённые через Telegram, сохраняются в SQLite и переживают перезапуск. Значения из `.env` используются как стартовые дефолты, если сохранённых настроек ещё нет.

## Логин через Telegram

Вместо ввода номера и кода в консоли бот сам проводит авторизацию: кнопка «Поделиться номером», ввод кода инлайн-клавиатурой, пароль 2FA текстом.

## Цены Gift Satellite

Задайте API-ключ (выдаёт @gift_satellite_bot) и базовый URL в меню `/settings`. Бот подставит актуальные цены по маркетам в сообщения владельцам подарков.

## Уведомления владельцам

При обнаружении нового уникального подарка зарегистрированный аккаунт пишет его владельцу по случайному шаблону из настроек (плейсхолдеры `{title}`, `{number}`, `{model}`, `{backdrop}`, `{price}`, `{link}`) и сообщает вам о результате.

**Автосообщения владельцу по умолчанию выключены.** Включить их можно в `/settings` кнопкой «Отправка владельцу», там же редактируются шаблоны.

### Шаблоны сообщений

В меню `/settings` → «✏️ Шаблоны сообщений» можно:

- добавлять новые шаблоны (до 10 штук);
- редактировать и удалять существующие;
- смотреть всё, что настроено.

При отправке владельцу каждый раз случайно выбирается один из шаблонов, чтобы сообщения не выглядели одинаковыми.

### Кто получает сообщения

Аккаунт пишет только владельцам, которые подходят под все условия (настраиваются в `.env`):

- подарок улучшен начиная с `OWNER_MIN_VALUE_TON` TON по рыночной цене Gift Satellite (0 — без ограничения);
- уровень репутации в Telegram (звёздный рейтинг) строго от `OWNER_MIN_REPUTATION` до `OWNER_MAX_REPUTATION` (по умолчанию 0–2);
- количество коллекционных подарков в профиле строго от `OWNER_MIN_GIFTS` до `OWNER_MAX_GIFTS` (по умолчанию 1–5).

Если владелец не проходит условия или данные о профиле недоступны, сообщение ему не отправляется — в административном алерте будет `⛔️ владельцу не отправлено: <причина>`. Ошибки доставки (`Too many requests` и похожие) тоже попадают в алерт, а при флуд-лимите отправка автоматически повторяется один раз с паузой.

## Скорость и охват

По умолчанию монитор проверяет 10 коллекций каждые 5 секунд. При 100 активных коллекциях конкретная коллекция проверяется примерно раз в 50 секунд. Чтобы следить за несколькими коллекциями быстрее, задайте, например:

```dotenv
GIFT_COLLECTIONS=PlushPepe,AstralShard
COLLECTIONS_PER_CYCLE=2
POLL_INTERVAL_SECONDS=3
```

Практические советы по ускорению:

- Самый безопасный способ ускорить мониторинг: ограничить `GIFT_COLLECTIONS` только нужными коллекциями.
- Для 1-5 коллекций обычно разумно начать с `COLLECTIONS_PER_CYCLE=1` и `POLL_INTERVAL_SECONDS=2`.
- Для 5-20 коллекций обычно хватает `COLLECTIONS_PER_CYCLE=2` и `POLL_INTERVAL_SECONDS=3`.
- Если начнут появляться `FloodWait`, верните значения назад: Telegram сам ограничивает слишком частые запросы.
- `MAX_NEW_GIFTS_PER_CHECK` не ускоряет поиск, а ограничивает, сколько новых номеров бот разберёт за один проход.

Слишком агрессивные значения могут вызвать `FloodWait`; приложение соблюдает обязательную паузу Telegram автоматически. Новые коллекции каталога обнаруживаются каждый час.

## Ubuntu / VPS

Пример для Ubuntu 24.04.

1. Установите зависимости:

```bash
sudo apt update
sudo apt install -y python3 python3-venv
```

2. Скопируйте проект на сервер, например в `/opt/gift-tracking`.

3. Создайте окружение и установите проект:

```bash
cd /opt/gift-tracking
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

4. Заполните `.env`.

5. Выполните первый запуск вручную, чтобы пройти Telethon-авторизацию и создать файл сессии:

```bash
cd /opt/gift-tracking
source .venv/bin/activate
gift-tracking --test-notification
gift-tracking
```

После ввода номера, кода и 2FA остановите процесс `Ctrl+C`.

6. Создайте systemd unit `/etc/systemd/system/gift-tracking.service`:

```ini
[Unit]
Description=Telegram Gift Tracking Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/opt/gift-tracking
ExecStart=/opt/gift-tracking/.venv/bin/gift-tracking
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Замените `User=ubuntu` на нужного пользователя.

7. Включите сервис:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now gift-tracking
```

8. Проверка логов:

```bash
sudo journalctl -u gift-tracking -f
```

Если на сервере корпоративный прокси или кастомный root CA, используйте `BOT_API_CA_FILE=/path/to/root-ca.pem`. Только как временный обход можно включить `BOT_API_INSECURE_SSL=true`.
